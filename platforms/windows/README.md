# DocFlow — Windows Desktop Edition

Локальная офлайн-версия DocFlow для Windows. Данные пользователя хранятся
только на его ПК, в `%LOCALAPPDATA%\DocFlow` — никогда на носителе, с которого
передана программа, и не внутри EXE.

## Сценарий «передал на флешке»

1. Соберите дистрибутив (см. ниже) на машине с Windows.
2. Скопируйте `DocFlow.exe` (или `DocFlowSetup.exe`) на флешку и передайте
   пользователю.
3. Пользователь устанавливает/запускает программу у себя — дальше флешка не
   нужна: при первом запуске автоматически создаётся `%LOCALAPPDATA%\DocFlow`
   с базой `database\docflow.db`, каталогами `imports`, `exports`, `logs`.
   Откроется браузер на `http://127.0.0.1:<порт>/app/` — это и есть интерфейс.
4. Работа полностью офлайн. Интернет не требуется.

## Сборка EXE (на машине с Windows)

```bat
pip install -r requirements.txt -r requirements-build.txt
pyinstaller platforms/windows/DocFlow.spec
```

Результат: `dist\DocFlow.exe` — один самодостаточный файл, его и копируете
на флешку.

## Вариант с установщиком (опционально)

Заготовка Inno Setup: `platforms/windows/installer/docflow.iss`.

1. Установите [Inno Setup](https://jrsoftware.org/isinfo.php).
2. Откройте `docflow.iss` в Inno Setup Compiler и скомпилируйте.
3. Результат — `dist\installer\DocFlowSetup.exe`: обычный мастер установки
   (каталог, ярлыки в меню Пуск и на рабочем столе).

## Первый запуск у пользователя

- Windows может показать SmartScreen «Windows защитила ваш ПК» — EXE не подписан
  сертификатом. Это ожидаемо: «Подробнее» → «Выполнить в любом случае».
- Откроется консольное окно DocFlow (не закрывайте его во время работы) и
  браузер с интерфейсом. Закрытие окна = корректная остановка сервера.
- Второй экземпляр не запустится (защита от конфликтов SQLite).

## Требования к ПК пользователя

- Windows 10/11 x64
- Любой современный браузер (Edge есть в системе, подойдёт)
- Интернет не нужен

## Обновление

Замените `DocFlow.exe` новой версией (или запустите новый установщик поверх).
Данные в `%LOCALAPPDATA%\DocFlow` не затрагиваются.

## Где что лежит

```text
%LOCALAPPDATA%\DocFlow\
├── database\docflow.db   ← база SQLite (данные пользователя)
├── imports\              ← загруженные файлы
├── exports\              ← сгенерированные документы
└── logs\docflow.log      ← журнал запуска
```
